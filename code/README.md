# ПЗ‑2. Минимальный макет

Сборка в Linux из папки `code`:

```bash
g++ -std=c++17 exchange.cpp timing.cpp -o isis_node
```

Запустите в отдельных терминалах `./isis_node 1` и `./isis_node 2`. После сообщения `joined` от обоих запустите `./isis_node 0` в третьем. Каждый узел выводит время каждого раунда и завершает работу после 10 раундов. Для повторного прогона запустите все три узла заново. Для запуска на разных ПК передайте вторым аргументом локальный IPv4-адрес каждого ПК.

`exchange.cpp` переключает очередь `0 → 1 → 2`. Каждый узел отправляет свой ID одним байтом в общую группу `239.10.0.1:5000`. Остальные ждут этот байт, после чего переходят к следующей очереди. В конце `timing.cpp` выводит длительность раунда в микросекундах. У узлов 1 и 2 замер включает ожидание пакета узла 0.

При потере пакета или пропуске узла ожидание может продолжаться до ручной остановки.
